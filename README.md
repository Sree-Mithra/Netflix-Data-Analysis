# Netflix Data Analysis Using Python and SQL

This project analyzes Netflix movies and TV shows using Python and SQL to identify trends in content, genres, countries, and release years.

## Tools and Technologies
- Python
- Pandas and NumPy
- SQLite and SQL
- Matplotlib and Seaborn
- Google Colab

## Project Activities
- Cleaned and explored the Netflix dataset using Pandas.
- Analyzed Movies and TV Shows.
- Used SQL queries to summarize content by release year, rating, country, and genre.
- Practiced SQL joins and subqueries.
- Created visualizations to identify content trends.
- Exported summary results to CSV files.

## Key Skills
Python, SQL, Data Analysis, Data Cleaning, Exploratory Data Analysis (EDA), Data Visualization.

## Project Files
- `Netflix_Data_Analysis_Python_SQL.ipynb` — Python analysis and SQL queries.
- `netflix.db` — SQLite database.
- `netflix_summary.csv` — Summary metrics.
- `netflix_top_genres.csv` — Genre analysis results.
- `netflix_top_countries.csv` — Country analysis results.

## Dataset
Netflix Movies and TV Shows dataset from Kaggle.

## Objective
To explore Netflix content trends by combining Python-based data analysis with SQL queries and visualizations.
